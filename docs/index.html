数据源对比
  • AkShare — 主源，东方财富数据 (代理可能影响)
  • Baostock — 备源，免费 A 股接口 (已验证可用)
  • 增量更新 — 只获取最新日期数据 (update_kline_incremental)
  • 质量检查 — 缺失值 / 连续性 / 异常值 (check_data_quality)
存储格式
  • Parquet — 列式存储，496 只仅 27.5 MB
  • 文件命名 — {symbol}_{start}_{end}_{adjust}.parquet
  • 索引文件 — data/index.json 记录全部元数据
  • 冗余清理 — normalize_k 自动移除冗余列

快速开始 5 Minutes to First Backtest
  1. 1 安装
    Terminal
    git clone git@github.com:1998x-stack/alpha101_factory.git cd alpha101_factory pip install -e .
  2. 2 获取数据
    Terminal
    python -m alpha101_factory.cli fetch
  3. 3 计算因子
    Terminal
    python -m alpha101_factory.cli factor --factors Alpha001
  4. 4 回测评估
    Terminal
    python -m alpha101_factory.backtest.run_bt --alpha Alpha001 --horizon 1
  5. 5 可视化
    Terminal
    python -m alpha101_factory.cli visualize --all --prefix Alpha
